# Plate sources

Every illustration in this directory is **public-domain** (pre-1928
publication, or institutionally released). Below: where each plate
comes from, where to fetch a higher-resolution canonical version,
the exact license, and the attribution string we publish in the
landing-page colophon.

Run `landing/scripts/fetch-hi-res-art.sh` from your local machine to
pull all the canonical hi-res versions in one go. (The build sandbox
on this repo blocks outbound HTTP to most cultural-heritage hosts, so
the fetch happens on your machine, then you push the binaries.)

## When you replace a file, also update:

1. **`landing/src/components/Page1Hero.tsx`** — `<ArtFrame src="...">` for the hero plate.
2. **`landing/src/components/Page2Pipeline.tsx`** — `art:` field on each stage entry.
3. **`landing/src/components/Colophon.tsx`** — the *Plates* line in the colophon should already cover the named sources; verify the attribution stays accurate after replacement.

The filename convention going forward is `<artist-or-author>-<short-subject>.jpg`, all-lowercase, hyphenated. Drop the watermarked / opaque legacy filenames once their replacements land.
